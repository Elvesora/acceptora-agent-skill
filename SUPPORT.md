# Support

## Usage and account help

Use the [Acceptora contact page](https://www.acceptora.com/contact) for account, billing, credential provisioning, canonical-origin, project-configuration, or hosted-service questions. Do not include credentials, private source material, customer data, or production payloads.

## Reproducible package defects

Open a GitHub bug report for a reproducible defect in the public package when it can be demonstrated with synthetic data. Include:

- package, contract, Python, Git, operating-system, and agent-client versions;
- the affected install, status, rollback, hook, MCP, REST, health, release, or recovery operation;
- the smallest safe reproduction and expected behavior;
- redacted error code, correlation ID, and output;
- whether the problem reproduces in a disposable trusted repository.

Do not use a public issue for account-specific data or suspected security vulnerabilities.

## Security issues

Follow [SECURITY.md](SECURITY.md) and use its private reporting process.
